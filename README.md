# MusicWhisper

一个手机优先的复古网络音乐播放器。它用 iPod 点击转盘的直接操作，配合手机步频、移动速度和位置场景，为当前行程选择更合适的音乐与 EQ 曲线。

## 使用

直接打开 GitHub Pages 页面即可使用。仓库已经包含 Pages Actions：推送到 `main` 后，GitHub Actions 会发布根目录静态文件。

本地预览可以在仓库目录运行任意静态服务器，例如：

```bash
python -m http.server 4173
```

然后打开 `http://localhost:4173`。

## 功能

- 点击转盘或按 `Space` 播放/暂停；左右方向键定位，`M` 静音。
- 导入本地 `mp3`、`wav`、`m4a`、`ogg` 等音乐。音频对象只在当前浏览器会话中使用。
- 点击「启用步频」后，支持 `DeviceMotionEvent` 的手机会在浏览器内估算步频；iOS 需要在点击后确认运动权限。
- 点击「使用定位」后，通过平滑后的速度区分步行、跑步、骑行和驾车。定位权限拒绝时，活动和场景仍可手动选择。
- 定位场景使用 OpenStreetMap Nominatim 的反向地理编码结果做粗略判断，映射为山路、城市公路、海边或森林。它是启发式判断，不是精确的风景识别；可用场景下拉菜单覆盖结果。
- 场景会切换五段 EQ 预设；也可以手动拖动曲线，或使用「旁路」暂时关闭 EQ。

## 隐私和浏览器限制

步频和定位数据只在浏览器内存中处理，不会发送到 MusicWhisper 服务。启用定位时，浏览器会向 Nominatim 请求一次反向地理编码；如果不希望发生网络请求，请使用手动场景。传感器和定位通常需要 HTTPS（`localhost` 例外），浏览器也可能限制后台或锁屏时的持续读取。

Web Audio、Media Session 和传感器 API 在不同浏览器中支持程度不同。即使浏览器不支持 EQ 或传感器，基础音频播放与手动模式仍可用。

## 样本音乐

演示曲目使用 MDN Web Audio Examples 仓库提供的公开示例音频地址，仅用于播放器交互演示。生产部署或二次分发时请替换为你拥有授权的音频，或直接导入自己的本地音乐。
